## Executive Conclusion

Nerya is not missing only small polish. The current bad experience is structurally explainable: Nerya is implemented as a **skill-first trading runtime**, while Hermes is a **general-purpose autonomous coding/operator agent** with a mature terminal/file/browser/tool harness, rich session memory, gateway breadth, TUI, command registry, scheduled delivery, and multiple environment backends.
