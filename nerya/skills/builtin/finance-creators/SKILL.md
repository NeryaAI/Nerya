# Finance Creators

Apply social-first finance frameworks as a research overlay. Treat reach as a
distribution fact, never as evidence of accuracy or investability.

## Activation Flow

1. CLASSIFY the request as `pure framework`, `fact-dependent`,
   `content review`, or `action-oriented`.
2. LOAD `references/creator-lenses.md`. Also load
   `references/full-playbook.md` for every `fact-dependent` or
   `action-oriented` request, and for comparisons, portfolio implications,
   content due diligence, or any paper/live proposal.
3. SELECT the smallest useful set: Serenity for AI or semiconductor supply
   chains; Unusual Whales for options flow, market-maker exposure, or public
   official disclosures; The Kobeissi Letter for macro events and cross-asset
   framing. Use one lens by default and no more than two unless requested.
4. For fact-dependent or action-oriented work, DEFINE the instrument,
   decision, horizon, and evidence cutoff. GATHER current facts with
   `market_research`, `equity_research`, `sec_filings`, `markets`, or
   `trading`. Give each material fact a source, `as_of` date, and stable ID.
   Label unverified user-supplied data `unverified user input`; never attach a
   creator source ID to it or use it alone for position guidance.
5. LABEL every material statement as `current fact`, `creator statement`,
   `framework inference`, `commercial context`, or `entertainment framing`.
6. RUN lenses independently. Preserve horizon, assumptions, conflicts,
   invalidation conditions, and source IDs; do not average conclusions.
7. RETURN implications, contrary evidence, missing data, incentive conflicts,
   confidence, and risk limits. If critical evidence is missing, stop at
   `Watchlist`. A recommendation remains a proposal, not an order.

## Boundaries

- Use reasoning patterns, not first-person impersonation or endorsement.
- Never use followers, engagement, urgency, or virality as an expertise score.
- Creator source IDs support methods and past statements, not current prices,
  holdings, disclosures, flows, fundamentals, or macro releases.
- Options flow is an observation, not proof of identity, intent, or direction.
- Public-official disclosures can be delayed, amended, incomplete, or
  economically ambiguous; verify the filing before drawing a conclusion.
- Surface subscriptions, products, affiliations, gifts, sponsorships, and
  position disclosures when they could shape the framing.
- If an exact quotation cannot be verified, paraphrase and label it
  `framework inference`; never fill a current-data gap from model memory.
- Require Risk Gate and Approval Gate for any later live-trading action.

## Reference Routing

- Always load `references/creator-lenses.md` for selection, mental models,
  voice constraints, failure modes, and framework source IDs.
- Load `references/full-playbook.md` for multi-lens work, evidence labeling,
  creator-content review, portfolio implications, and paper/live proposals.
- Load only the needed provenance file under `references/research/`:
  `01-writings.md`, `02-conversations.md`, `03-expression-dna.md`,
  `04-external-views.md`, `05-decisions.md`, or `06-timeline.md`.
