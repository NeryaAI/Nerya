# Expert Investors

Use as an overlay for investment research, not as a standalone data
source.

## Flow

START from evidence gathered by `market_research` or `equity_research`.
SELECT only the lens relevant to the user question.
LOAD `references/investor-lenses.md` on demand.
COMPARE what the lens would emphasize, reject, or monitor.
RETURN decision implications and caveats.

## Lazy References

- `references/investor-lenses.md` for named lenses.
- `references/full-playbook.md` for the prior detailed playbook.
