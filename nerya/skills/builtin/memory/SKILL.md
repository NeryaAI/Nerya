# Memory

Use when the answer depends on prior sessions, durable user
preferences, repeated failures, or long-term project facts.

## Flow

IF the user asks to remember:
WRITE the smallest durable fact.

IF the user asks what happened before:
SEARCH memory before re-deriving.

IF a fact is stale-prone:
STATE that memory is historical and verify live state when needed.

IF the fact is procedural:
CONVERT it into a skill proposal, not a raw memory blob.
